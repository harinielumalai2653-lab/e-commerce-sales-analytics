E-Commerce Sales Analytics

Project Overview

This project focuses on analyzing e-commerce sales data to identify sales trends, customer behavior, and business insights.

Objectives

- Analyze overall sales performance.
- Identify top-performing product categories.
- Understand monthly sales trends.
- Analyze customer purchasing patterns.
- Generate meaningful business insights.

Tools Used

- Python
- Pandas
- NumPy
- Matplotlib

Project Work

- Data loading and exploration
- Data cleaning and preprocessing
- Exploratory Data Analysis (EDA)
- Data visualization
- Business insights generation

Project File

- "sales analytics.ipynb"

Conclusion

This project helped me understand how data analytics can support business decisions through data analysis and visualization.
